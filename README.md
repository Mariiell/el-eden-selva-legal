## Activar GitHub Pages

En **Settings → Pages**, seleccionar **Build and deployment → Deploy from a branch**. En **Branch** elegir `main` y carpeta `/(root)`, luego **Save**. Revisar que el sitio quede visible desde HTTPS:

- `https://mariiell.github.io/el-eden-selva-legal/`
- `https://mariiell.github.io/el-eden-selva-legal/privacidad.html`
- `https://mariiell.github.io/el-eden-selva-legal/condiciones.html`
- `https://mariiell.github.io/el-eden-selva-legal/eliminacion-datos.html`

Las URL anteriores son **rutas esperadas**; antes de ingresarlas en Meta deben abrirse públicamente y mostrar el documento correcto.

## Verificación necesaria antes de usar con clientes

Estas páginas constituyen una **versión inicial**. El responsable del negocio debe verificar que el nombre/identidad legal y el canal de contacto sean correctos y que realmente pueda atender solicitudes de datos personales; comprobar las finalidades, proveedores de procesamiento, plazos de conservación y condiciones de reservas. La publicación de páginas legales no acredita por sí sola cumplimiento regulatorio ni aprobación de Meta.

Guía normativa orientativa: Ley peruana N.° 29733 y Reglamento aprobado por D.S. N.° 016-2024-JUS (vigente desde 31/03/2025).

El servicio web del hospedaje y el backend de SELVA se despliegan **por separado** en infraestructura apropiada; GitHub Pages solo publica estas páginas estáticas.
